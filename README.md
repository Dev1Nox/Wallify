# Wallify
## Wallify  Wallify es la app definitiva para personalizar tu Android con fondos de pantalla de calidad, de forma rápida y sin complicaciones.  Explora una galería con una selección de wallpapers, previsualízalos a pantalla completa y aplícalos con un par de toques — a tu pantalla de inicio, a la de bloqueo, o a ambas.
